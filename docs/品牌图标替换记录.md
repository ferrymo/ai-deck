## 透明底调整

用户反馈 Claude 和 Codex 的黑底影响观感后，同步处理了这两个品牌以及 Gemini CLI、Trae、ZCode、Antigravity Tools、OpenCode，共 7 份图标。SVG 内嵌原始 PNG 并施加透明遮罩，保留原始轮廓；白色单色标志改用石墨色。原始下载素材保持不变，可通过 `scripts/prepare-brand-cutouts.mjs` 重建显示资源。

生成式抠图预览出现边缘噪点与形变，因此未纳入项目。最终界面使用从原始像素计算的透明遮罩。

类型检查、Biome、2 个界面测试通过；17 个图标映射均成功加载，并检查了浅色、深色、窄窗口及完整图标汇总。

7 份透明资源的四角 Alpha 均为 0。新版目录包位于 `release/transparent-icons/win-unpacked`，实机启动后商店中的 16 张品牌图片（含顶部展示）均通过本地文件/内联数据解码检查。没有覆盖此前正在使用的目录包。
