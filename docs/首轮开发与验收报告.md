# AI Deck 首轮开发与验收报告

日期：2026-10-17 · 版本：0.1.0 · 平台：Windows 11 x64

## 交付结论

从需求文档起步，完成可运行的 Electron 客户端基础版，覆盖七个页面及本机发现、版本检查、实例管理、Skill 备份恢复和持久化的纵向流程。已生成 Windows 解包应用，并在独立临时数据目录运行真实打包版验证。

**本轮不等同于完整 MVP 完成。** 三类 CLI 的安装/修复/自动升级、Skill 上游同步、安装计划与运行时重新绑定、签名 NSIS 的旧版升级演练仍未完成。界面与能力开关明确保留这些边界。

本机运行时扫描保留了一个真实异常：Node 17.9.1 目录存在，但 node.exe 不存在；界面显示不健康运行时与扫描提示，没有伪报可用。

浏览器标准版本下载中途被 CDN 断开；本次 UI 流程使用本机已缓存 Chromium headless 1243 运行，通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 显式指定。默认配置仍使用 Playwright 管理的对应浏览器版本；原生客户端验证使用实际 Electron，不依赖该替代浏览器。

所有文件恢复测试在随机临时目录中进行。真实本机只读扫描不会安装、升级工具或切换 nvm。烟雾数据目录在 `%TEMP%/ai-deck-smoke-*`，保留用于排查；截图位于 `.impeccable/review`（不入 Git）。

## 技术方案落地差异

- 应用依赖按方案使用 Electron 44.9.0、React 19.3.1、TypeScript 7.0.2、electron-vite 6、Vite 8、better-sqlite3 13.0.3、builder/updater 26.17.0/6.8.10。
- 本次开发使用已安装 Node 22.23.1 和 pnpm 11.10.0，均满足所用构建链，未全局升级工具或改变 nvm 链接。`packageManager` 固定实际验收版本；Node 26/pnpm 12 尚未补做兼容矩阵。
- pnpm 识别到 better-sqlite3 隐式原生构建和 Squirrel 安装器脚本。使用已附带 Node-API 预编译模块，显式禁用这两个不需要的构建脚本；Electron 下载允许执行。打包不重新编译 SQLite。
- SQLite 首版保存有版本的工作区快照，尚未拆成完整关系表；任务重启后不重放文件操作。源基线、安装计划、进程身份恢复等在安装执行器阶段补齐。
